# UEPL Attendance Dashboard

An interactive employee attendance dashboard for **Utsah Engineering Pvt. Ltd.** to monitor attendance performance, analyze department-wise statistics, and track employee attendance records.

## Features

- **Overview:** Attendance KPIs, status breakdown, and daily attendance trends.
- **Department:** Department-wise attendance percentage, employee count, and attendance statistics.
- **Employees:** Search, sort, and filter employee attendance records.
- **Daily Attendance:** View daily attendance status, in-time, and out-time.
- **Attendance Calendar:** Visualize employee attendance by date.
- **Excel Upload:** Upload monthly Performance Register files in `.xlsx` and `.xls` formats.
- **Data Management:** Replace existing data or append uploaded records.
- **Upload History:** View upload details and data quality summaries.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- SheetJS (XLSX)

## Usage

1. Open the dashboard in a web browser.
2. View attendance insights through the available tabs.
3. Use filters and search to analyze employee and department records.
4. Click **Upload New Excel** to upload a Performance Register.
5. Select the update mode and apply the changes to refresh the dashboard.

## Project Purpose

To simplify attendance monitoring, improve data visibility, and support data-driven workforce management through interactive visualizations and Excel-based reporting.

**Developed for:** Utsah Engineering Pvt. Ltd. (UEPL)
